# Rebeca Ferreira Confeitaria — Site Oficial

Site da **Rebeca Ferreira Confeitaria**, confeitaria artesanal especializada em bolos personalizados, doces finos e kits para presente.

---

## O que é esse projeto?

Esse é o site da confeitaria, criado para que clientes possam conhecer os produtos, ver fotos dos bolos, encontrar o endereço e entrar em contato para fazer pedidos diretamente pelo WhatsApp.

---

## O que tem no site?

- **Página inicial** com foto da loja e botão para pedido no WhatsApp
- **Horário de funcionamento** (segunda a sábado, das 9h às 18h30)
- **Seção de produtos** com os principais itens: bolos personalizados, doces finos e kits para presente
- **Galeria de fotos** com imagens reais dos bolos feitos na confeitaria
- **Diferenciais** da Rebeca Ferreira Confeitaria
- **Depoimentos** de clientes
- **Nossa história**
- **Mapa** com a localização da loja no Google Maps
- **Botão flutuante do WhatsApp** sempre visível para facilitar o contato
